***Network Security Lab – University Project***

This repository documents my practical work from the Network Security course. It summarizes the experiments I performed, the security concepts I explored, and the key insights I gained throughout the lab.

The project covers hands-on analysis of network security concepts using Kathará/Docker, Wireshark, Kali Linux, and Aircrack-ng. Topics include packet filtering, ARP attacks, WPA/WPA2/WPA3 security, VPN tunneling, WireGuard/IPsec, TLS/SSH, and Tor. Network traffic and security protocols were examined through packet captures and controlled attack scenarios.
